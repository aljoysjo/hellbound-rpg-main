🔄 FLUJOS IMPLEMENTADOS
1. FLUJO PRINCIPAL - ACCIÓN USUARIO:
Usuario escribe acción → StoryInput → submitAction() →
POST /api/free_input → Backend procesa → Respuesta con:
- narrative (historia)
- game_state (estado actualizado)
- random_event (si aplica)
- discoveredItems (si aplica)
2. FLUJO EVENTOS ALEATORIOS D20:
Backend recibe acción → shouldTriggerRandomEvent() →
  ├─ Verifica actionsSinceLastEvent >= 4
  ├─ Calcula probabilidad (30% base + contextuales)
  └─ Si true → analyzeGameContextForEvents() →
      ├─ Detecta modo (sandbox/campaña)
      ├─ Determina temas (detective/adventure/horror)
      └─ filterEventsForContext() →
          ├─ Filtra por triggers (['explorar', 'investigar'])
          └─ rollD20AndApplyConsequences() →
              ├─ Math.random() * 20 + 1
              ├─ Aplica consecuencias (health, items, skills)
              └─ Retorna resultado completo

Frontend recibe → setRandomEvent() → RandomEventModal →
  ├─ Muestra descripción + dificultad
  ├─ Animación D20Dice
  └─ Resultado + consecuencias
3. FLUJO DISCOVERED ITEMS (REORDENADO SEGÚN CHATGPT):
Narrativa generada → extractItemsFromNarrative() →
  ├─ availableItems (para modal)
  └─ alreadyPickedItems (auto-pick)

PASO 0B: Auto-Pick (SECUNDARIO)
